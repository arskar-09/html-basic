HTML5 기초 핵심 문법

기본 구조 HTML5 표준 템플릿

모든 HTML 파일은 아래 기본 구조로 시작해야 한글 깨짐 및 반응형이 정상 작동합니다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>페이지 제목</title>
</head>
<body>
  <!-- 화면에 보일 내용 작성 -->
</body>
</html>

필수 태그 실무 자주 쓰는 태그 7가지

  • <h1> ~ <h6> : 제목 (h1이 가장 큼)
  • <p> : 본문 단락 텍스트
  • <div> : 영역을 묶는 블록 상자 (가장 자주 사용)
  • <span> : 문장 속 특정 글자만 감싸는 인라인 상자
  • <a href="주소"> : 다른 페이지로 이동하는 링크
  • <img src="경로" alt="설명"> : 이미지 출력 태그
  • <button> : 클릭 가능한 버튼

개념 Block vs Inline 속성 차이

Block 요소 (div, p, h1): 한 줄을 전부 차지하며 줄바꿈이 일어남. (너비/높이 지정 가능)

Inline 요소 (span, a): 글자 크기만큼만 영역을 차지하며 옆으로 붙음. (너비/높이 지정 불가)

CSS3 기초 & 레이아웃

HTML 요소에 디자인과 레이아웃을 입히는 핵심 문법입니다.

선택자 CSS 작성 및 선택자(Selector)

/* 1. 태그 선택자: 모든 button에 적용 */
button { background-color: blue; }

/* 2. 클래스 선택자(.): class="btn" 인 요소에 적용 (실무 주력) */
.btn { color: white; border-radius: 4px; }

/* 3. 아이디 선택자(#): id="header" 인 고유 1개 요소에 적용 */
#header { height: 80px; }

박스모델 Margin과 Padding

모든 HTML 요소는 박스 형태입니다. box-sizing: border-box;를 설정해야 패딩이 박스 크기를 늘리지 않습니다.

.box {
  width: 300px;
  padding: 20px;       /* 박스 안쪽 여백 */
  margin: 10px;        /* 박스 바깥쪽 여백 */
  border: 1px solid #ccc; /* 테두리 선 */
  box-sizing: border-box; /* 필수 설정! */
}

레이아웃 Flexbox 정렬 (기본)

부모 요소에 display: flex;를 주면 자식 요소들을 자유자재로 정렬할 수 있습니다.

.parent {
  display: flex;
  justify-content: center; /* 가로 정렬 (center, space-between 등) */
  align-items: center;     /* 세로 정렬 (center, flex-start 등) */
  gap: 16px;               /* 자식 간격 */
}

JavaScript 기초 문법

웹 페이지의 로직과 동적 상호작용을 담당합니다.

변수 const & let

옛날 방식인 var는 사용을 금지합니다.

const siteTitle = "에이전시"; // 재할당 불가능한 변수 (기본으로 사용)
let visitCount = 0;          // 재할당 가능한 변수

visitCount = visitCount + 1; // 가능!

데이터 배열(Array)과 객체(Object)

// 배열: 순서가 있는 목록
const members = ['김신입', '이선배', '박팀장'];
console.log(members[0]); // '김신입'

// 객체: Key-Value 데이터 (실무 백엔드 데이터 형태)
const user = {
  name: '김신입',
  role: 'Frontend Developer',
  age: 25
};
console.log(user.role); // 'Frontend Developer'

DOM 제어 HTML 요소 가져와서 바꾸기

// 1. HTML 요소 선택
const title = document.querySelector('#main-title');
const btn = document.querySelector('.submit-btn');

// 2. 이벤트 등록 (클릭 시 실행)
btn.addEventListener('click', () => {
  title.textContent = "문구가 변경되었습니다!";
  title.style.color = "red";
});
